# Cloud Journey 2026

Studying AWS with an offensive security mindset. Companies run on the cloud, and misconfigured cloud environments are some of the most common real-world attack paths. To break the cloud, I first need to understand how it's built.

## Study Schedule
AWS gets one dedicated session every Sunday. Keeping it to one focused day lets me go deep without crowding my lab and coding work.

## Focus Areas
| Area | Why It Matters for Offensive Security | Status |
|---|---|---|
| Cloud fundamentals | Shared responsibility — knowing what the customer is supposed to secure | In progress |
| IAM | Overly broad permissions are a top cloud attack path | Planned |
| Networking (VPCs) | Builds directly on my home lab networking skills | Planned |
| Storage (S3) | Misconfigured buckets expose sensitive data | Planned |
| Compute (EC2) | Understanding what attackers target once inside | Planned |
